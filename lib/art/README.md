# 立绘目录

手机页「正在执行」那块轮播的角色立绘放在这里。**目录为空也能跑**——页面会退成只有台词气泡，
不报错、不占位。

## 放什么

| 文件名 | 用途 |
|---|---|
| `work-1-ready` … `work-9-talking` | 九种轮播姿势（收到 / 翻资料 / 打键盘 / 核对 / 思考 / 跑 / 等待 / 冲刺 / 说话） |
| `work-10-talking` | 说台词那一张，独立图层（见 `page.html` 的 `SPEAK_POSE`） |
| `whale-girl` | **兜底图**。凑不齐上面那套时，九张都退到它，人至少还在 |

名字必须是小写字母、数字与连字符，后缀只接受 `.webp` / `.png` / `.svg`（由 `lib/page.js` 的白名单卡死）。
页面按 `webp → png → 兜底` 的顺序叠背景，缺哪张跳哪张，所以**混用格式也没问题**。

放好后重启 DSH 即可——`page.html` 与立绘列表是启动时读进内存的。只放一张时，命名成 `whale-girl.png`
就够了，不需要改代码。
