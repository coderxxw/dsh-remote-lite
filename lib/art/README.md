# 立绘位（可选，默认空）

手机页「正在执行」那块**可以**摆一张角色图，但现在是空的——目录里只有这份说明，
界面上一像素都不占。

## 怎么启用

1. 把一张图放进本目录，命名 **`mascot.webp`**（或 `mascot.png`）。
2. 重启 DSH（`dsh web`）。
3. 手机页跑任务时，它会出现在台词气泡左边，宽度 84px。

想关掉就把文件删掉再重启，或者干脆留着文件、把 `mascot.webp` 改名——**没有文件时
页面不会留空框**，这一行会自动变回「只有气泡、占满整行」。

## 为什么是固定名字

不扫目录、不挑一张"最新"的：这条路要可预测。目录里多放几张备用图不会影响
显示哪一张，只有 `mascot.webp`（优先）和 `mascot.png` 会被读到。

## 实现位置

| 位置 | 作用 |
|---|---|
| `lib/page.js` → `artFileName()` | 启动时探测这两个文件名，返回命中的那个或 `null` |
| `lib/server.js` → `GET /mini/api/version` | 把结果放在响应的 `art` 字段里 |
| `lib/page.html` → `applyArt()` | 有值才取消 `#workArt` 的 `hidden`；没有就保持隐藏 |

格式只认 `.webp` 与 `.png`（**不收 SVG**：SVG 可以带 `<script>`，同源发出去等于给了它
一段执行环境）。图片按 `width: 100%; height: auto` 铺满 84px 的位子，
所以**竖图比方图更合适**，横图会被压得很扁。
