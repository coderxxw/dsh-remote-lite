# 立绘目录

手机页「正在执行」那块轮播的角色立绘放在这里。**目录为空也能跑**——页面会退成只有台词气泡，不报错、不占位。

## 现在有哪些

| 文件 | 姿势 | 台词 |
|---|---|---|
| `work-1-ready.webp` | 敬礼待命 | 收到，这就去办 |
| `work-2-reading.webp` | 捧书在看 | 先翻翻资料 |
| `work-3-typing.webp` | 抱着笔记本敲键盘 | 正在写… |
| `work-4-checking.webp` | 举放大镜核对 | 让我检查检查 |
| `work-5-thinking.webp` | 托腮思考 | 嗯…让我想想 |
| `work-6-running.webp` | 原地小跑 | 跑一遍看看 |
| `work-7-waiting.webp` | 背手等着 | 还在忙，再等我一会儿 |
| `work-8-sprinting.webp` | 冲刺 | （纯动作，不出台词） |
| `work-9-talking.webp` | 开口说话 | 说台词时的专用图层 |
| `whale-girl.webp` | 站立 | 兜底：缺哪张就退到它 |

均为 512×512、WebP、真透明，单张约 40 KB，合计约 0.4 MB。

## 命名与格式

名字必须是小写字母、数字与连字符，后缀只接受 `.webp` / `.png` / `.svg`（由 `lib/page.js` 的白名单卡死）。
页面按 `webp → png → 兜底` 的顺序叠背景，缺哪张跳哪张，所以**混用格式也没问题**。

放好后重启 DSH 即可 —— `page.html` 与立绘列表是启动时读进内存的。

## 这套图是怎么来的

AI 生成（文生图出基准角色，再以它为参考逐张派生姿势），参照的是社区「鲸鱼娘」的视觉语言：
蓝渐变长发、呆毛、鲸鳍耳、鲸尾、深藏青女仆裙。**不是任何一位作者的原图。**

单张整图，不是雪碧图，所以页面对它用 `data-frames="1"`：`background-size: contain`、
底边对齐、不切帧。若你换成原作那种「一张图并排两帧 / 六帧」的雪碧图，把对应 `POSES` 条目的
`frames` 改回 2 或 6 即可，那两套关键帧还在。
